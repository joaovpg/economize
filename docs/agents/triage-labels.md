# Labels de triage

As skills usam cinco papéis canônicos de triage. Este arquivo mapeia esses papéis para os labels usados no issue tracker deste repositório.

| Label em mattpocock/skills | Label neste tracker | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Precisa ser avaliada por uma pessoa mantenedora |
| `needs-info` | `needs-info` | Aguarda mais informações de quem reportou |
| `ready-for-agent` | `ready-for-agent` | Está especificada e pronta para um agente autônomo |
| `ready-for-human` | `ready-for-human` | Requer implementação humana |
| `wontfix` | `wontfix` | Não será realizada |

Quando uma skill mencionar um papel, use o label correspondente desta tabela. Edite a coluna da direita caso o vocabulário do tracker mude.
